# 💬 Katalk Analyzer (카톡 대화 분석기)

`katalk-analyzer-zeta.vercel.app` 스타일의 **100% 브라우저 기반 카카오톡 대화 분석기** 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **완전한 프라이버시 & 보안 (Client-side 100%)**
   - 대화 파일(`.txt`, `.eml`)이 어떠한 외부 서버로도 전송되지 않습니다.
   - 방문자의 웹 브라우저 메모리 안에서만 즉시 계산되어 개인정보 유출 걱정이 없습니다.
2. **다양한 카카오톡 내보내기 형식 완벽 지원**
   - 📱 **모바일 이메일 내보내기(`.eml`)** 지원 (`YYYY년 M월 D일 오전/오후 H:MM, 이름 : 대화`)
   - 💻 **PC 버전 대화 내보내기(`.txt`)** 지원 (`[이름] [오전/오후 H:MM] 대화`)
   - 장문 줄바꿈(Multi-line) 대화 유지
   - 사진, 동영상, 이모티콘, 삭제된 메시지, 입장/퇴장 시스템 메시지 자동 분리
3. **직관적이고 모던한 토스 스타일 대시보드**
   - 🏆 **참여자별 대화 랭킹 (수다왕)**: 대화 수, 글자 수, 지분율(%), 상위 5명 도넛 차트
   - ⏰ **24시간 시간대별 & 요일별 대화량**: 피크 타임 및 활동 분포 바 차트
   - 📈 **일자별 대화 타임라인**: 가장 불타올랐던 날 추이 영역 차트
   - 🎖️ **재미있는 캐릭터 뱃지**: 수다왕, 정성 타자왕, 새벽 올빼미, 미디어 요정
   - 📋 **리포트 원클릭 복사**: 단톡방에 바로 붙여넣기할 수 있는 깔끔한 요약본 복사
   - ✨ **샘플 데이터 둘러보기**: 파일 없이도 1초 만에 대시보드 체험 가능

---

## 🚀 로컬 실행 방법

```powershell
cd web
npm.cmd run dev
```

터미널에 표시되는 로컬 주소(예: `http://localhost:5173`)로 접속하시면 즉시 사용하실 수 있습니다.

---

## 🌐 Vercel 무료 배포 방법

### 방법 A: Vercel CLI (가장 간단)
```powershell
cd web
npx.cmd vercel
```
화면 지시에 따라 계정을 로그인하면 즉시 `https://내프로젝트.vercel.app` 링크가 생성됩니다.

### 방법 B: GitHub 연동
1. 이 프로젝트(`web` 폴더 또는 레포지토리)를 GitHub에 푸시합니다.
2. [Vercel](https://vercel.com) 대시보드에서 `Add New...` > `Project`를 누르고 GitHub 저장소를 선택합니다.
3. Root Directory를 `web`으로 설정하고 **Deploy**를 누르면 자동으로 배포됩니다.
